# Local-first com Corpus de Demo fictício

O lembrai é um assistente pessoal, mas o repositório é público e serve de portfólio. Decidimos que o produto é genérico e local-first: dados reais do Usuário vivem apenas na máquina dele (`data/`, fora do git), enquanto o repositório versiona um Corpus de Demo — Perfil e Notas de uma pessoa fictícia — usado para demonstração pública e como base dos evals (perguntas com resposta conhecida). A alternativa (usar dados reais) tornaria o repo impublicável e os evals subjetivos; esta escolha resolve os dois problemas de uma vez.
